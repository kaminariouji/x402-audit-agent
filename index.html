crypto-bot-honesty-audit

A self-revenue x402 service: exposes a paid HTTP API (POST /audit) and an MCP tool (audit_bot_code) that scans a JS/TS crypto-bot source file for the bug patterns that make a bot report income it never earned — testnet tokens counted as USD, silent-zero balances from failed RPC, cooldown key mismatches, non-existent faucet endpoints, and attempts counted as results. Payments are 0.05 USDC on Base (eip155:8453) via HTTP 402, settling directly to the seller wallet with no human in the loop.
