crypto-bot-honesty-audit

A self-revenue x402 service: a paid HTTP API plus nine MCP tools, no signup and no API key. Two products:

  1. Crypto-bot honesty audit (POST /audit, MCP audit_bot_code, 0.01 USDC) — scans a JS/TS crypto-bot source file for the bug patterns that make a bot report income it never earned: testnet tokens counted as USD, silent-zero balances from failed RPC, cooldown key mismatches, non-existent faucet endpoints, attempts counted as results.
  2. Keyless market data (0.01 USDC per call) — GET /price, /search_tokens, /markets, /tvl, /stablecoins, /trending, /gas, with matching MCP tools get_token_price, search_tokens, top_markets, chain_tvl, stablecoin_supply, trending_tokens, gas_prices.

Each unpaid call returns HTTP 402 whose challenge offers both settlement networks — USDC on Base (eip155:8453) and USDC on Solana (solana:5eykt4UsFv8P8NJdTREpY1vzqKqZKvdp) — settling directly to the seller wallet with no human in the loop. On Solana the facilitator is the feePayer, so receiving costs the seller nothing.
